Abinod – Produktdokumentation

Ambiten-Dokumente

Ambiten ist das erste Produkt der Reihe Abinod: eine kontextbezogene Laufzeitumgebung für moderne Multi-Tenant-Anwendungen. Installieren Sie es über npm und greifen Sie anschließend hier auf die vollständige Dokumentation zu, sobald die Dokumentation in diese Website integriert ist.

npm install ambiten

Auf npm anzeigen Dokumente anzeigen Zurück zu Abinod
